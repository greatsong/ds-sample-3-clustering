# 데이터 출처

- 파일: `kbo_hitters_2026_full.csv`
- 출처: KBO 공식 기록실(https://www.koreabaseball.com)의 타자 기본 기록 1·2 화면과 주루 기록 화면을 팀별로 모아 선수명·팀으로 합친 것입니다. 2026 정규 시즌 144경기 전체 기록입니다.
- 포지션·생년월일·키·몸무게는 modudata의 `kbo_player_profiles_2026.csv`(2026 등록 명단)에서 선수명·팀으로 붙였고, 11명은 짝을 찾지 못해 빈칸입니다.
- 받은 날짜: 2026-10-15
- modudata에는 아직 올라가지 않은 파일이라 이 저장소의 사본이 원본입니다.
- 크기: 364행(선수 1명이 1행) · 25열
- 개인 단위 정보: 프로 선수의 공개 경기 기록이며 학생·일반인 정보는 없습니다
